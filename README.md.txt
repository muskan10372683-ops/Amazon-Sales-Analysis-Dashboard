# Amazon Sales Analysis Dashboard

## Project Overview

This project is an interactive sales dashboard created using Microsoft Excel to analyze Amazon sales data.

## Objectives

* Analyze category-wise sales.
* Track monthly sales trends.
* Compare order statuses.
* Analyze regional sales.
* Identify the top 5 products by sales.

## Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers and Timeline Filters

## Dashboard Features

* Category-wise sales analysis
* Status-wise sales visualization
* Regional sales analysis
* Monthly sales trends
* Top 5 products analysis
* Interactive filters

## Key Learnings

* Data analysis
* Data visualization
* Excel dashboard creation
* Business reporting

## Conclusion

This project demonstrates how Excel can be used to analyze sales data and create an interactive dashboard.
